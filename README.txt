SUNGPU MULTIPURPOSE SOCIETY — STATIC WEBSITE

QUICK START
1. Extract this ZIP file completely.
2. Open the sungpu-website folder.
3. Double-click index.html to open it in your browser.

No installation, Node.js, database, API keys or build step is required.
Keep index.html, styles.css and the assets folder together.

OPTIONAL: RUN A LOCAL WEB SERVER
If Python 3 is installed, open a terminal inside sungpu-website.
Windows:
  py -m http.server 8000 --bind 127.0.0.1
Linux / macOS:
  python3 -m http.server 8000 --bind 127.0.0.1
Then open http://localhost:8000 in your browser.
Press Ctrl+C in the terminal to stop the server.

EDITING
- index.html: page text, sections, navigation and contact details.
- styles.css: colours, typography, spacing and responsive layouts.
- assets/: selected photos, logo and downloadable society profile.
Edit with a text editor such as VS Code, save, and refresh your browser.

TESTING
- Resize the browser to check the mobile layout.
- Click navigation links to move between sections.
- Open the society profile link to view the PDF.
- Email and telephone links open your configured mail or calling application.

The site uses plain HTML and CSS, with local images and system fonts.
It has no contact form or backend. All visual content works offline;
emailing and calling depend on your installed applications and connection.
